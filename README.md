Programming Literacy Language (PLL)
An original educational minded, human-readable programming language designed to teach programming literacy.
A RevLab LLC project.

What is PLL?
Programming Literacy Language (PLL) is an educational programming language designed to help people understand programming concepts through familiar, structured, human-readable instructions.
Traditional programming languages require learners to understand specific syntax and conventions before they can effectively express their ideas in code.
PLL approaches this differently.
Instead of making syntax the starting point, PLL puts understanding first. It provides a structured language through which learners can explore variables, logic, conditions, repetition, functions, and other fundamental programming concepts.
The goal isn't simply to teach someone another programming language.
The goal is to make programming itself easier to understand.
Philosophy
PLL is built around several core principles:
    • Familiarity: Writing instructions should feel approachable, like writing in a notebook or document.
    • Understanding over syntax: Learners should understand what an instruction does, not simply memorize how to write it.
    • Structured expression: A small collection of predictable sentence patterns provides consistency without unnecessary complexity.
    • Transferable knowledge: Concepts learned through PLL should apply to conventional programming languages.
    • Learning through experimentation: Learners should be encouraged to write, execute, modify, and troubleshoot their programs.
    • Progressive independence: Programming terminology and explanations should support learners initially, gradually giving them room to work independently.
Design Goals
PLL is intended to become a real, structured programming language.
Its development goals include:
    1. An original language syntax and grammar.
    2. A working interpreter.
    3. Built-in educational explanations.
    4. Clear and understandable error messages.
    5. Support for increasingly complex programs.
    6. A future read-only translation view connecting PLL instructions to conventional programming languages.
    7. An eventual compiler and virtual machine.
Python, JavaScript, and C are important reference languages for evaluating how well PLL concepts transfer to conventional programming.
Development Philosophy
Every language pattern should have:
    1. One clearly defined meaning.
    2. A plain-English reading.
    3. An associated conventional programming term.
    4. A built-in educational explanation.
    5. A conceptual counterpart in conventional programming languages.
Features will be introduced when they teach meaningful, transferable programming concepts.
PLL is not intended to reproduce every feature of existing programming languages. Its scope is focused on supporting programs of meaningful complexity while maintaining its educational purpose.
Project Road-map
Phase 1 - Language Design
    • Establish project purpose and philosophy.
    • Define target audience.
    • Establish language design principles.
    • Develop original syntax.
    • Define language grammar.
    • Establish initial language specification.
Phase 2 - Interpreter
    • Develop language tokenizer.
    • Develop parser.
    • Implement variables and basic data types.
    • Implement input and output.
    • Implement expressions and operators.
    • Implement conditional logic.
    • Implement repetition and iteration.
    • Develop educational error handling.
    • Establish automated testing.
Phase 3 - Language Expansion
    • Introduce functions.
    • Introduce additional data structures.
    • Improve program organization.
    • Expand educational explanations.
    • Develop increasingly complex example programs.
Phase 4 - Compiler and Virtual Machine
    • Design intermediate representation.
    • Develop compiler.
    • Define virtual machine architecture.
    • Develop instruction set.
    • Implement bytecode execution.
Phase 5 - Project Lattice Integration
    • Develop language learning materials.
    • Explore read-only language translation.
    • Integrate PLL into the Project Lattice learning environment.
Project Status
Current stage: Initial language design and syntax prototyping.
PLL is under active development. The language specification, implementation, and supporting educational materials will evolve as the project progresses.
Project Ownership
Developed under RevLab LLC.
PLL is intended to eventually become part of Project Lattice, a broader educational environment focused on making computing, programming, and technology more approachable through experimentation and interactive learning.
